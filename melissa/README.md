# Reproducible Melissa space–time reconstruction

Please read [`README_ES.md`](README_ES.md) for installation, execution and limitations. The archived 61 observed horizontal-wind fields are assimilated; the model reconstructs an unobserved vertical component by divergence and lower-boundary penalties. This is reconstruction rather than forecasting. Core five scripts are retained in `src/` from the user's uploaded experiment files; driver scripts live in `scripts/`.
